# 连续用机休息提醒（0.8）

侧栏新增「休息提醒」，默认关闭。它关注本轮连续使用电脑的时间，与某个应用的每日额度分开。

## 开启与设置

1. 勾选「启用连续用机休息提醒」。
2. 从20、30、45、60、90分钟中选择一个时间点，或输入5–240之间的整数分钟。
3. 选择强度，点击「保存休息提醒」。保存会从现在重新计时，并解除该功能的今日忽略；原有“今日全部静默”仍生效。

这些间隔供用户自行选择，不作为医学处方或个人用眼状况的判断。

| 强度 | 提醒方式 |
| --- | --- |
| 轻度 | Windows系统通知及所选声音，不抢焦点；每再使用一个所选间隔后提醒 |
| 中度 | 置顶弹窗，等待点击操作，不主动请求前台焦点 |
| 严重 | 请求唤起TraceTime并将提醒置前；Windows可能限制置前，失败则闪烁任务栏 |

点击「预览提醒与设置音效…」可为每档选择系统音、柔和单音、清脆提醒、静音或自定义PCM WAV，支持音量、试听和效果预览。WAV最长10秒、2MB，支持8/16位、单/双声道。保存时复制到数据目录；取消不更改设置。休息音效独立于应用额度音效，复用相同编辑器与播放能力。预览不改变计时、开关或今日静默。

## 什么时间会累计

- 切换软件、关闭主窗口到托盘或最小化时，连续用机仍累计。
- 阅读、思考或看视频时没有键鼠输入，也不自动认定已经休息。
- 暂停记录、维护数据时暂停累计，恢复后继续，不补算暂停时间。
- 已知锁屏或休眠暂停累计；连续满5分钟后重置，短暂离开保留此前时长。
- 点击「现在开始休息」或弹窗的「开始休息」后，暂停本轮累计。满5分钟归零；提前结束保留此前时长。休息结束需要点击「结束休息，继续使用」。此操作不会暂停原始应用使用记录。
- 未知的长采样空档不补时，也不假定发生过休息。退出程序后再次启动从零开始；已保存的开关、间隔、强度与今日忽略会恢复。

连续使用不会因午夜自动清零；「今天不再提醒休息」仅抑制当天提醒，次日自动恢复。应用时长限制页的「今日全部静默」同时覆盖休息提醒。

## 提醒出现后

提醒文案为：“让视线离开屏幕，看看远处，轻轻眨眼。也可以起身活动一下，给双眼和身体留一点休息时间。”

| 操作 | 结果 |
| --- | --- |
| 开始休息 | 进入主动休息，满5分钟归零；可以在休息页提前结束 |
| 5分钟后提醒 | 再累计5分钟使用后提醒，暂停/锁屏不消耗该时间 |
| 今天不再提醒 | 当天不弹休息提醒，可在休息页恢复；不修改每应用额度 |

额度弹窗、休息弹窗和效果预览互斥。主动休息期间暂停呈现新的应用额度弹窗，结束休息后恢复判断。功能不会强制锁屏、关闭软件或阻止继续使用；休息提醒不发送邮件、不联网。

## 本地数据与轻量实现

配置在当前用户数据目录的 `break-reminder.json`；独立音效在 `break-reminder/reminder-sounds.json` 与 `break-reminder/sounds/`。连续时长只保存在内存中，不新增使用记录、进程遍历或专用后台计时器，复用原有采集状态事件。
