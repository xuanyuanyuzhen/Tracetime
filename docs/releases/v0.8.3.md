# TraceTime 0.8.3 · 后台提醒汇总优化与升级接续

整合首批Playbook优化，并将程序元数据、侧栏和包名统一为0.8.3。包含未单独发布的[0.8.2启动项接续修复](v0.8.2.md)。

- 后台额度检查改为读取应用汇总，省去不需要的时间线构建；前台停留与扣除空闲后的两种时长保持原有口径。
- 加入固定时区、模拟时钟的时间边界与汇总等价回归，累计118项场景通过；构建默认锁定依赖恢复，配置Windows CI与每周依赖更新检查。
- 90天合成数据的读路径测量中，每次托管分配减少约22%；短时进程测量未得到一致的CPU或常驻内存改善。方法与限制见[性能说明](../PERFORMANCE.md)。
- 大幅墙钟回拨后的时间轴重叠仍是已记录限制，此版本没有改变历史时区归属或数据库结构。

本地运行目录为`artifacts/release/TraceTime-0.8.3-win-x64`，ZIP及`.zip.sha256`直接放在`artifacts/release`下，与旧版并列。仍需.NET 10 Desktop Runtime x64。

发布包已执行隔离流程验证，覆盖采集、单实例、模拟服务、历史恢复、提醒、设置重启与启动项接续。启动项测试使用内存替身，没有实测Windows重启登录；长期常驻、真实AI/SMTP服务及全套DPI组合仍待进一步验证。

本版不代表整份Playbook全部完成：应用身份别名、持久化汇总表、完整UI重构、安装器/签名、自动快照和双进程继续保留在后续计划。

升级时先从旧版托盘退出，再启动新目录中的`TraceTime.exe`；已有数据沿用当前用户的数据目录。启动项接续边界见[升级说明](../UPGRADING.md)，验证证据见[验证记录](../VALIDATION.md)。
