# TraceTime 0.8.2 · 升级后自启动接续（本地修复版）

修复更换程序目录后，重启Windows仍启动旧版的问题。此版本未单独公开，其改进包含在[0.8.3](v0.8.3.md)中。

- 已开启的TraceTime启动项在新版成功启动后自动更新到当前路径；未开启的保持关闭，Windows中禁用的状态保持不动。
- 设置页正确识别旧版的自启动选择，显式保存更新路径、取消保存移除旧路径；保存失败恢复原命令，不误写为当前路径。
- 已注册程序可识别为更高版本时，不自动回退；未知命令不覆盖。
- 旧实例仍在运行且注册路径不同，手动启动新版时提示先退出旧版，避免误以为已完成切换。
- 演示、独立数据、验证及开发运行不修改自启动；不新增后台服务、依赖或周期性检查。

从托盘退出旧版后，启动本修复包的 `TraceTime.exe` 即可接续原有选择。仍需.NET 10 Desktop Runtime x64。具体操作与固定目录方案见[升级说明](../UPGRADING.md)；已验证范围见[验证记录](../VALIDATION.md)。
