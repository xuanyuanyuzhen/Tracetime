# TraceTime 0.7.0

发布日期：2026-11-10。

TraceTime 的首个 GitHub Release：面向 Windows x64 的本地前台应用时间记录工具，同时提供前台停留与扣除空闲后两种时长。本次发布包含此前已在本地完成的 0.5–0.7 功能，以及重新整理的 README 和使用指南。

## 下载与运行

在本 Release 的 **Assets** 中下载：

- `TraceTime-0.7.0-win-x64.zip`：Windows x64 应用包，完整解压后运行 `TraceTime.exe`。
- `TraceTime-0.7.0-win-x64.zip.sha256`：ZIP 的 SHA-256 校验值。

此包依赖 **Microsoft .NET 10 Desktop Runtime x64**，无需 SDK；请从 [Microsoft 官方下载页](https://dotnet.microsoft.com/en-us/download/dotnet/10.0) 选择 **.NET Desktop Runtime → Windows x64**。已验证平台为 Windows 11 x64。请保留解压后的整个文件夹，GitHub 自动生成的 `Source code` 仅为源码。

## 本次公开发布内容

- **搜索与日期跳转**：按名称查找每日应用和额度规则，跳转上 / 下个有记录日或最近有记录日，搜索不改变总计与占比分母。
- **提醒快捷操作**：记住常用临时分钟，支持今日全部静默及恢复，保留每条规则的原有设置。
- **历史管理**：查看历史体积，备份全部历史、按月归档和恢复。默认不删除；恢复前自动备份，按范围替换，重复恢复不叠加时长。
- **全天图表**：分时柱状图、状态时间轴、时长占比环图，以及所选小时的应用双时长和完整时间片。
- **更完整的提醒**：三档提醒与音效预览、自定义短 PCM WAV、超时应用再次进入提醒、可提前开启的 1–120 分钟临时使用。
- **可选 SMTP 邮件**：全局与每应用默认关闭；支持 STARTTLS、凭据保护、异步发送和手动重试。
- **浏览与外观**：概览整页滚动、可收起侧栏，以及原有明暗模式、三种材质和调色盘。
- **保留既有能力**：托盘采集、双口径统计、应用额度、本地 7 / 30 日分析、可选手动 AI 分析、CSV 导出与记录日历。

## 升级与数据

升级前先备份历史，从旧版托盘选择「退出」，再运行新版本。同一 Windows 用户会继续使用 `%LOCALAPPDATA%\TraceTime`，替换程序不会主动清空历史。如果程序位置改变且已启用开机启动，请在新版重新保存启动选项。

历史归档只包含使用记录，不包含规则、外观或账号配置；需要复制完整数据目录时请先退出应用。记录和归档未加密，AI / SMTP 凭据使用当前 Windows 用户 DPAPI 保护。

不记录窗口标题、网址、文档名、键盘内容或屏幕截图。空闲不等于未工作。AI 仅在预览确认后手动发送汇总，邮件仅在主动配置并开启后发送。

## 验证与已知限制

- 已通过 80 项确定性场景、8 项隔离应用流程、单实例及主题 / 图表 / 搜索 / 历史恢复 / 偏好重启检查；所有数据写入验证使用隔离目录。
- AI 与邮件通过模拟服务验证；真实服务投递、实际锁屏 / 休眠、多显示器、长期性能和大型归档仍需进一步实测。
- 当前没有安装器、代码签名或自动更新；没有手机端、多设备同步、网站粒度统计或强制关闭应用功能。

完整操作与验证范围见 [项目 README](https://github.com/xuanyuanyuzhen/Tracetime/blob/v0.7.0/README.md) 和 [验证记录](https://github.com/xuanyuanyuzhen/Tracetime/blob/v0.7.0/docs/VALIDATION.md)。
