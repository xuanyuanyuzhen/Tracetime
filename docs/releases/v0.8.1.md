# TraceTime 0.8.1 · 轻量化优化

本版本聚焦轻量常驻，保留0.8.0的全部功能：连续用机休息提醒、自定义音效与强度、应用占比饼图、图表秒级悬停提示及侧栏CPU/内存显示。

- 托盘启动延迟加载概览和应用图标；隐藏/最小化不再刷新界面报告，恢复窗口时立即补刷新。
- 时间线按需构造，收起释放派生视图；复用全天汇总、排行行控件与冻结画刷。
- 复用前台识别缓冲区，避免每秒重复分配大缓冲；不改变1秒兜底采样、双口径及提醒规则。
- Windows x64包仅包含对应SQLite原生库，移除旧构建混入的其他平台文件；仍需.NET 10 Desktop Runtime x64。
- ZIP约19.88→4.41MiB；同机短测托盘平均工作集约120.57→93.70MiB，概览/最小化CPU时间也下降。具体测量条件与完整数据见性能说明，不作为固定占用承诺。
- 提供可重复的隔离资源测量脚本。98项场景和正式包完整验证通过；数据与边界见[性能说明](../PERFORMANCE.md)及[验证记录](../VALIDATION.md)。

## 下载与升级

下载本页Assets中的 `TraceTime-0.8.1-win-x64.zip`，安装 **Microsoft .NET 10 Desktop Runtime x64** 后完整解压，运行 `TraceTime.exe`。同页提供 `.zip.sha256` 校验文件，GitHub自动生成的Source code为源码包。

升级前建议通过「设置与数据 → 历史备份与归档」备份记录，再从旧版托盘菜单选择「退出」后启动新版。用户数据目录仍为 `%LOCALAPPDATA%\TraceTime`；更换程序位置且已启用开机启动时，在新版重新保存启动选项。休息提醒仍默认关闭，按连续使用累计，主动休息或锁屏/休眠满5分钟后重置。
