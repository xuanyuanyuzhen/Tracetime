# TraceTime 0.8.0

本次发布合并0.7.1的全部本地改进，并新增可选的连续用机休息提醒。Windows x64，依赖Microsoft .NET 10 Desktop Runtime x64。

## 新增：休息提醒

- 侧栏独立入口，默认关闭，由用户开启。提供20/30/45/60/90分钟预设和5–240分钟自定义。
- 按本轮连续使用电脑累计，切换应用不重置，键鼠空闲不直接等同休息；主动休息或已知锁屏/休眠满5分钟重置，暂停记录/数据维护不补时。
- 复用轻度通知、中度弹窗、严重置前三档，保留系统/内置/自定义WAV、音量、试听与预览；休息音效独立保存。
- 使用看远处、眨眼、起身休息的提示文字，提供开始休息、稍后5分钟和今天不再提醒；今日全部静默覆盖休息提醒。
- 应用额度提醒与休息弹窗互斥，避免同时叠加。休息提醒不联网、不发邮件，不强制锁屏或关闭软件。

完整规则和操作见 [连续用机休息提醒](../BREAK-REMINDERS.md)。

## 一并发布的0.7.1改进

- 修复侧栏鼠标点击后残留焦点边框，保留键盘导航提示。
- 时长分析新增应用占比饼图，支持双口径；超过6个应用时前5单独显示，其余汇总。
- 趋势柱图、概览柱图/时间轴/环图及饼图提供精确到秒的悬停详情；静止指针下刷新数值，离开后关闭。
- 明暗切换上方显示TraceTime自身CPU/内存，每2秒更新；窗口隐藏/最小化停止资源采样。

## 下载与升级

下载Assets中的 `TraceTime-0.8.0-win-x64.zip`，同名 `.zip.sha256` 可核对完整性。先从旧版托盘菜单退出，将新包完整解压并运行 `TraceTime.exe`。历史记录、额度、外观与原有音效仍沿用当前用户的数据目录；新休息功能默认关闭。

连续用机进度只在当前进程保留，重启从零开始；不会补算离线时间。系统通知、实际声卡及焦点行为受Windows设置影响。验证范围见 [验证记录](../VALIDATION.md)。
