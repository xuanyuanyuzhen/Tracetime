# 应用额度与时长分析（0.4）

## 设置每日额度

进入「应用时长限制」，选择已记录过的应用、每日分钟数、统计口径和提醒强度，点击「保存应用额度」。找不到应用时，确认 TraceTime 正在记录，打开目标应用并让它处于前台几秒，再点击「刷新应用」。不从磁盘扫描或手工填写未记录的应用。

一个应用对应一条规则，最多100条。范围1–1440分钟，按当前电脑本地日期每日累计；可以选择前台停留或扣除空闲后。空闲回扣仍遵循原有规则，不把扣除空闲后的数值当作工作时长。

| 档位 | 到额度后的行为 |
| --- | --- |
| 轻度 | Windows 托盘通知和提示音，不主动切换窗口。系统静音、通知设置或免打扰可能影响呈现。 |
| 中度 | 显示置顶提醒，不主动请求焦点；需要点击提醒内按钮关闭。 |
| 严重 | 请求把 TraceTime 带到前台并显示置顶提醒；Windows 阻止前台切换时闪烁任务栏。需要点击提醒内按钮关闭。 |

提醒不会关闭或禁止目标应用。选择「知道了，今天不再提醒」会结束当天提醒；「再用10分钟提醒」以该规则口径下继续累计十分钟为条件，不是等待十分钟。暂停或锁屏期间不累计、不新弹提醒，恢复后继续；正常关闭主窗口到托盘仍检查额度。

额度检查约每5秒一次。严重提醒优先；中度被严重提醒替换时，待确认状态保留，稍后继续处理。同日状态会保留到重启后，跨日重置。保存修改或重新启用规则会重新判断当天累计；已超过额度时会再次提醒。删除规则不会删除使用记录。

## 本地分析

「时长分析」可查看近7天或30天，并更改截止日期。提供：

- 每日趋势：宽条是前台停留，内侧细条是扣除空闲后，悬停查看数值；下方可以展开每日数据。
- 应用排行：切换两种口径，时长和占比同步变化。
- 本地摘要：有记录日期、合计、按有记录日期计算的日均、最高占比应用和记录最多的一天。

今天可能尚未结束，无记录不等于没使用。数据源仍是已有本地记录，不能补回程序未运行的时间。没有 API Key 时这些功能照常使用。

## 配置 AI 回顾

在分析页点击「配置 AI 服务」，弹窗中选择：

1. **服务类型**：OpenAI官方、本机服务、兼容/自定义；选项填入常见地址，可继续调整。
2. **地址方式**：基础地址会自动补上 `/chat/completions`；完整接口按填写内容使用。例如基础地址 `https://api.openai.com/v1`。HTTP仅支持本机，远端必须HTTPS。
3. **API Key**：留空时只会保留同一服务已保存的密钥；换到不同服务需重新输入。保存后使用Windows当前用户DPAPI加密；「清除已存密钥」在点击保存后生效，取消则保留旧配置。
4. **分析模型**：点击「获取模型列表」后从服务返回的列表选择，也可切到「手动填写」。模型列表可能含非文字模型，请按服务商说明选择。获取列表只发送鉴权，不发送使用记录；失败时仍可手动填写。
5. **配置名称**：可选，帮助辨认当前连接。点击保存才写入，取消不会更改现有配置。

主页面显示配置名称、模型与接口。点击「生成发送预览」，检查将发送的日期、应用汇总及两种时长；默认匿名名称，可自行关闭。勾选同意后点击「发送并分析」。内部分析模板固定由程序维护，不提供用户编辑或复制入口；旧版配置中的自定义提示词会忽略，地址、模型与加密密钥保留。

每次请求或配置变更都需要重新确认；打开配置或更改范围会取消进行中的请求。不会自动定时调用AI，不会自动改额度。发送内容不包含路径、应用内部键、原始时间片、窗口标题、网址、文档、按键或截图。服务商会收到预览的汇总数据，可能计费，以其条款为准。

请求不跟随重定向；分析90秒超时，响应超过256KiB停止读取；模型列表20秒超时，最多保留500个ID。支持复制汇总数据，或导出本地摘要与最近一次带日期范围的AI结果，不包含密钥或内部模板。

## 应用图标与记录日期

图标来自应用本地可执行文件资源，在概览、分析排行、额度选择/规则及提醒中共享；首次提取异步进行，不阻塞记录。缓存位于数据目录 `cache/icons`，使用哈希文件名、32像素PNG，内存与磁盘各最多256项；缓存约30天后尝试刷新。应用已卸载但缓存尚在时仍可使用图标；提取失败或没有图标时显示统一占位和应用名称。此缓存是图标资源，不是屏幕截图，也不发送给AI。

日期选择器中，带点高亮表示有前台使用记录，灰色表示没有记录。空闲期间仍属于前台记录，不会因另一口径为零而失去标记；暂停空档不算使用记录。选中日期的实色与记录点分别表达「选择」和「有记录」，今天另有边框；鼠标提示也会说明记录状态。

无记录日期仍可选择，用于查看空档或导出连续区间。数据新增/删除后标记自动更新，跨午夜记录分别标记实际涉及的本地日期。

## 当前边界

尚未做应用强制阻断、网站细分、后台AI、账号同步或历史AI会话。未提供真实API凭据，所以外部服务未实连；HTTP成功/错误/取消/超时和界面状态使用模拟接口验证。系统通知、声音和所有Windows环境下的前台焦点表现仍需实际使用中确认。
