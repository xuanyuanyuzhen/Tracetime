# 每日概览、额度与分析设计约定

模式：Operate。当前版本 0.7，更新于 2026-11-02。在既有 Windows WPF 界面中增加应用搜索、记录日跳转、快捷提醒和历史管理，保留主题、双时长定义、全天分布与核心查看路径。

## Direction contract

- THESIS：看清可核对的应用时长；前台停留与扣除空闲后分别呈现。
- OWN-WORLD：Fluent 风格的明暗语义颜色、清晰数据行、原生桌面行为；用户选择液态玻璃、柔和或极简及强调色。
- STORY：今天 → 查看双时长与全天分布 → 选择时段或应用 → 完整时间片；需要自我提醒时设置每日额度、再次进入选项或提前临时使用，需要回顾时查看 7/30 天本地分析。AI 经预览并同意后手动发送；邮件经全局与规则双重启用后按提醒事件自动发送。外观页继续即时保存模式、材质与配色。
- FIRST VIEWPORT：左侧五项导航（每日概览、应用时长限制、时长分析、外观与主题、设置与数据）；概览右侧为日期、两个时长面板、全天分布入口和排行；展开后可选图表与时段。记录状态、暂停和托盘提醒持续可见，侧栏可收起为图标。
- FORM：继承0.1的仪器活动轨迹与数据行，保留原始 seed 6de5dd52 作为历史方向记录。此次用户明确要求常见平台参考与玻璃等可选风格，按功能扩展直接编码。
- FINISH：0.7 的 artifacts/qa/build-0.7-reviewed.txt 记录 80/80 通过；8 项应用流程与单实例见 release-0.7.0-495c6765，最终截图/模拟/新进程偏好见 release-0.7.0-86d9b8f3 和 verify-0.7-capture-final.txt（均在 artifacts/qa）。86d9b8f3/independent-review.md 中唯一 P2 清理反馈项已 resolved / remaining clear / ship，限该列项复核。没有操作真实用户历史或进行大规模性能实测；本文仅局部归档，不启动应用或追加测试。

## 用户确认

首次启动：跟随系统 + 液态玻璃；之后记住所选明暗模式、风格与颜色。选择跟随系统时继续响应系统明暗变化。主题偏好独立于使用记录。

应用额度只作提醒，不结束或封锁目标应用。前台停留包含空闲，扣除空闲后的时长单独呈现；空闲不代表未工作。“知道了”仅确认本次，“今天不再提醒”抑制当天本地与邮件提醒。AI 只有用户核对预览、勾选同意并点击发送后才提交汇总；可选 SMTP 邮件全局和规则默认关闭，用户启用后按事件自动发送。

## 页面与提醒（当前 0.7）

- 应用时长限制：已有记录应用 ComboBox 与刷新入口在前，随后是 1–1440 分钟额度、双口径、三档提醒 RadioButton、再次进入和规则邮件开关。可选邮件面板与设置入口位于今日规则之前。规则卡片显示当天进度、剩余临时使用和开关状态，提供临时使用/调整/取消、编辑、暂停/启用、今天不再提醒和删除；没有应用时指导先记录目标应用，历史名称在进入页面时加载。
- 时长分析：近 7/30 天及截止日控制范围，三个互斥视图为每日趋势、应用排行、本地摘要。趋势用宽条和细条区分双口径，提供悬浮数值与可展开数据表；图表为 WPF 绘制，没有新增图表库。
- AI 回顾：置于本地分析下方，0.4配置已移至独立弹窗，密钥用 PasswordBox 输入及当前用户 DPAPI 保存。默认匿名名称；完整预览不含密钥，发送须勾选同意，可取消、复制汇总、导出文本；提示词为内部模板。配置或范围变化会使预览失效。只发送汇总，不发送路径、原始时间片、标题、网址、文档、按键内容或截图。
- 提醒：轻度用托盘通知与所选音效；中度窗口置顶但不主动激活，严重请求前台焦点，失败时闪烁任务栏。窗口宽 480 DIP、最小高 340 DIP、按内容增高至工作区上限，内容可滚动；“知道了”“临时使用 N 分钟”“今天不再提醒”分别确认本次、按常用分钟开启前台累计额度（首次 10 分钟）、抑制今天本地与邮件。临时到期使用明确标题，预览仍不改变真实状态。

## 参考与实现边界

参考 Microsoft Fluent 2 的色彩/材质规则、Linear 官方UI重设计中的导航与信息层级、Apple Liquid Glass 官方说明中的材质层次。玻璃在此实现为WPF内部半透明渐变面板与高光边缘，不读取桌面，也不声称采用Apple光学实现。

最终设计规则见根 DESIGN.md；旧版快照在 docs/design-v0.1.md。证据和限制见 docs/VALIDATION.md；页面可滚动，截图为视口，不代表全部内容同时可见。

历史 0.3 的 35/35 场景、发布包、DPAPI 与 AI 模拟验证证据位于 artifacts/qa/release-0.3.0-d704fd3f，独立审查的历史应用名称项已 resolved / ship，限当次范围。代表视图为其中 overview.limits.png、overview.analysis.png、overview.reminder-severe.png，均来自隔离演示。系统真实通知、声音、焦点唤起，以及系统主题/高对比度切换不因代码和模拟验证而视为全量实机通过。

## 0.4 图标、配置与日期优化

沿用同一布局和主题。应用图标共享缓存并与名称同时出现，覆盖每日/分析排行、额度下拉和规则、提醒、普通与空闲时间片；无应用的中断行保持文字语义。

AI主页面缩为服务摘要和配置入口；独立弹窗以服务类型→地址方式→密钥→模型的选项组织，保存/取消常驻底部，较矮窗口内部滚动。获取模型列表为显式动作且不发送使用记录；模板固定在程序内部，数据预览与复制不包含模板。

日历的实心点和底色说明有记录，灰色说明无记录但可选；选中状态不替代记录标记。新删记录与本地跨日正确更新，空闲前台仍为有记录。

40/40场景、缓存/旧配置迁移/模型选择/日期刷新及0.4运行包完整验证通过。独立复核唯一遗漏“时间片列表图标”已补并确认resolved/ship。证据为artifacts/qa/release-0.4.0-4151246d。真实外部AI和系统级全量验收范围不扩大。

## 0.5 分布、预览与浏览

查看路径为日期/双时长 → 直接进入全天分布或查看排行 → 选择图表和小时 → 软件双时长 → 完整时间片。完整日期中明确区分无输入、已知中断、未记录、未来；不把无记录原因或生产力推断为事实。应用筛选标在时间片旁，防止误读全局图表数值。

五个原生导航入口支持72DIP图标模式和200DIP文字模式；悬停名称、自动化名称、主题和展开入口保留。每日概览优先整页滚动，长时间片保留虚拟化和独立滚动条/键盘。图表类型与侧栏状态独立保存并重启恢复。

提醒配置按档位→声音→音量→试听/预览→保存排列。音效资源本地复制，取消不保存，效果预览不更改限额或今日状态。页面遵循现有动态主题，固定底部保存/取消，较矮窗口内容可滚动。准确验证结果见 WORKLOG.md。

## 0.6 再次进入、临时使用与邮件

再次进入默认开启，可按规则关闭；同次前台停留去重，TraceTime 自身窗口不形成新访问。返回超时应用按原档位提醒；关闭此选项后每日额度提醒一次，临时使用到期仍独立提醒。规则可暂停，重新保存会重置当天状态。

临时使用可提前开启，窗口宽 480 DIP、SizeToContent.Height、工作区高度上限、26 DIP 内边距，内容滚动。5/10/15/30 快选与 1–120 整数输入后才提交；按目标应用前台累计，空闲消耗，后台/暂停/锁屏不消耗。到期即使未达每日额度也提醒；同日重启恢复、本地跨日结束。卡片支持调整或取消，调整从当前累计值重新给定分钟数；主动开启会解除今天忽略状态。

EmailConfigWindow 默认 600×740 DIP、最小 480×460，26 DIP 内边距，固定标题与保存/取消，中间表单滚动。先解释发送范围、启用开关和收件邮箱，再提供展开的 SMTP 主机/端口/发件邮箱/账号/授权码。仅支持 STARTTLS（通常 587，不支持 465），凭据使用 PasswordBox 与当前用户 DPAPI；换主机、端口、账号或发件邮箱须重输，取消不保存，保存不发测试邮件。

邮件全局与规则均默认关闭。日期、应用名、事件和所选口径累计时长发送给配置的服务及收件人；每日额度事件另含额度，不含路径、原始明细或屏幕内容。每日额度与每次临时到期分别去重，再次进入不重复发邮件；临时使用只暂缓本地提示，不延后已到每日额度的邮件。页面以摘要和可展开的今日最近 12 条状态呈现异步队列，失败手动重试、跨日不补发。结果未知时提示先查收件箱，“发信服务已接收”不等于已送达；今天忽略及关闭规则取消未发邮件，已经提交的邮件不能撤回。

本轮仅扩展既有 WPF 控件与主题，没有新视觉体系。用户说明及待定的 Flutter 可行性评估见 [REMINDERS-AND-ROADMAP.md](REMINDERS-AND-ROADMAP.md)，手机端未开发。

历史 0.6 的 65/65 场景及正式包证据为 artifacts/qa/release-0.6.0-620b41eb；ship 仅涵盖当时七张截图与源代码抽查，不扩展真实 SMTP、音频、系统通知/焦点、锁屏或休眠的实测范围。

## 0.7 搜索、快捷操作与历史管理

概览日期下方提供上个/下个/最近有记录日；空闲前台算记录，日历仍能选空日期。名称搜索紧邻排行，额度搜索同时筛选应用选择与下方规则；清空可恢复完整列表，无匹配时给出说明并禁用保存。搜索不改变双时长总计、原名次、占比分母和图表范围。

临时使用保留 5/10/15/30 快选与 1–120 输入，新增可取消勾选的常用时长记忆，首次 10 分钟，后续提醒按钮复用，取消弹窗不保存偏好。今日全部静默/恢复并入已有额度标题栏，底部用文字持续标记；覆盖搜索隐藏和新规则，保留每应用启停/今日忽略，计时及临时额度继续，次日结束。恢复后按原规则重新判断，取消的邮件不自动补发。

设置页“历史备份与归档”先显示数据库/WAL大小、时间片数量和归档内容，再排列全历史备份、恢复、打开目录，之后是月份选择和默认未勾选的移除选项。`.ttarchive` 未加密，只含历史应用身份/名称/可执行路径及使用/空闲/中断区间和范围信息，不含规则、外观、偏好或凭据。只读事务读取含已提交 WAL 的一致快照；创建时继续记录，默认保留原数据。结束月份才允许归档后另行确认移除，校验并锁住归档后再删除对应月份。

恢复使用原生文件选择与确认框，先预览范围、时区及三类区间数量，确认绑定 SHA；先生成安全备份，再事务替换范围，不叠加时长。范围外历史和规则/外观/凭据保留，完成后当天全局静默。维护时禁用冲突操作，移除/恢复暂缓采集并恢复原暂停状态；成功提交后临时副本清理失败显示成功加清理提示/位置，不能显示“原历史保留”。使用说明见 [HISTORY-AND-QUICK-ACTIONS.md](HISTORY-AND-QUICK-ACTIONS.md)。
