# 每日概览、额度与分析设计约定

模式：Operate。0.3 在既有 Windows WPF 界面中扩展应用额度与分析，保留 0.2 的主题、双时长定义与核心查看路径。

## Direction contract

- THESIS：看清可核对的应用时长；前台停留与扣除空闲后分别呈现。
- OWN-WORLD：Fluent 风格的明暗语义颜色、清晰数据行、原生桌面行为；用户选择液态玻璃、柔和或极简及强调色。
- STORY：今天 → 切换口径 → 排行与应用选择 → 时间线；需要自我提醒时设置应用每日额度，需要回顾时查看 7/30 天本地趋势、排行或摘要；AI 仅在预览并同意后手动发送。外观页继续即时保存模式、材质与配色。
- FIRST VIEWPORT：左侧五项导航（每日概览、应用时长限制、时长分析、外观与主题、设置与数据）；概览右侧仍是日期、两个时长面板、排行与折叠时间线；记录状态、暂停和托盘提醒持续可见。
- FORM：继承0.1的仪器活动轨迹与数据行，保留原始 seed 6de5dd52 作为历史方向记录。此次用户明确要求常见平台参考与玻璃等可选风格，按功能扩展直接编码。
- FINISH：0.3 已有 35/35 核心场景、发布包流程、DPAPI 与 AI 模拟验证证据。最终补验证据为 artifacts/qa/release-0.3.0-d704fd3f；独立审查唯一历史应用名称项已 resolved，ship 限该次界面审查范围。本文仅据现有实现和证据局部更新，不追加测试。

## 用户确认

首次启动：跟随系统 + 液态玻璃；之后记住所选明暗模式、风格与颜色。选择跟随系统时继续响应系统明暗变化。主题偏好独立于使用记录。

应用额度只作提醒，不结束或封锁目标应用。前台停留包含空闲，扣除空闲后的时长单独呈现；空闲不代表未工作。AI 不自动发送，只有用户核对预览、勾选同意并点击发送后才向所填接口提交汇总。

## 0.3 页面与提醒

- 应用时长限制：已有记录应用 ComboBox 与刷新入口在前，随后是 1–1440 分钟额度、双口径和三档提醒 RadioButton。下方卡片显示当天进度，提供编辑、暂停/启用、今天不再提醒和删除；没有应用时指导先记录目标应用，历史名称在进入页面时加载。
- 时长分析：近 7/30 天及截止日控制范围，三个互斥视图为每日趋势、应用排行、本地摘要。趋势用宽条和细条区分双口径，提供悬浮数值与可展开数据表；图表为 WPF 绘制，没有新增图表库。
- AI 回顾：置于本地分析下方，0.4配置已移至独立弹窗，密钥用 PasswordBox 输入及当前用户 DPAPI 保存。默认匿名名称；完整预览不含密钥，发送须勾选同意，可取消、复制汇总、导出文本；提示词为内部模板。配置或范围变化会使预览失效。只发送汇总，不发送路径、原始时间片、标题、网址、文档、按键内容或截图。
- 提醒：轻度用托盘通知与声音；中度窗口置顶但不主动激活，严重请求前台焦点，失败时闪烁任务栏。窗口宽 480 DIP、最小高 340 DIP、按内容增高至工作区上限，内容可滚动；“今天不再提醒”与“再用 10 分钟提醒”均完整可达。

## 参考与实现边界

参考 Microsoft Fluent 2 的色彩/材质规则、Linear 官方UI重设计中的导航与信息层级、Apple Liquid Glass 官方说明中的材质层次。玻璃在此实现为WPF内部半透明渐变面板与高光边缘，不读取桌面，也不声称采用Apple光学实现。

最终设计规则见根 DESIGN.md；旧版快照在 docs/design-v0.1.md。证据和限制见 docs/VALIDATION.md；页面可滚动，截图为视口，不代表全部内容同时可见。

0.3 代表视图为最终证据目录中的 overview.limits.png、overview.analysis.png、overview.reminder-severe.png，均来自隔离演示。系统真实通知、声音、焦点唤起，以及系统主题/高对比度切换不因代码和模拟验证而视为全量实机通过。

## 0.4 图标、配置与日期优化

沿用同一布局和主题。应用图标共享缓存并与名称同时出现，覆盖每日/分析排行、额度下拉和规则、提醒、普通与空闲时间片；无应用的中断行保持文字语义。

AI主页面缩为服务摘要和配置入口；独立弹窗以服务类型→地址方式→密钥→模型的选项组织，保存/取消常驻底部，较矮窗口内部滚动。获取模型列表为显式动作且不发送使用记录；模板固定在程序内部，数据预览与复制不包含模板。

日历的实心点和底色说明有记录，灰色说明无记录但可选；选中状态不替代记录标记。新删记录与本地跨日正确更新，空闲前台仍为有记录。

40/40场景、缓存/旧配置迁移/模型选择/日期刷新及0.4运行包完整验证通过。独立复核唯一遗漏“时间片列表图标”已补并确认resolved/ship。证据为artifacts/qa/release-0.4.0-4151246d。真实外部AI和系统级全量验收范围不扩大。
